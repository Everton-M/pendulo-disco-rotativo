# CAD review and Simscape validation

## Validated package

The original SolidWorks files remain in this folder. The corrected native package is stored in `corrected-solidworks/` and contains:

- `rotating_disk_pendulum_corrected.SLDASM`;
- the four corrected `.SLDPRT` components;
- `simscape-export-corrected/rotating_disk_pendulum_corrected.xml`;
- the four STEP geometry files generated by Simscape Multibody Link.

The original assembly is preserved as a reference and was not overwritten.

## Geometry used by the analytical model

| Item | Definition |
| --- | --- |
| `O-A` | vertical distance `a` |
| `A-B` | arm length `b` |
| `B-C` | vertical distance `c` |
| `C-D` | `[0, r, h]` in frame B2 |
| `D-E` | pendulum length `l` |

Therefore, `z_D = a + c + h`. The parameter `r` is the radial distance in the disk plane, while `h` is the vertical offset from `C` to `D`.

## Corrected kinematic structure

The validated assembly has exactly three rotational degrees of freedom:

1. `alpha`: revolute connection between the fixed base and the arm about the vertical axis;
2. `beta`: revolute connection between the arm and disk about the disk vertical axis;
3. `psi`: revolute connection between the disk and pendulum about the local transverse axis X2.

The beta and psi pivots use the SolidWorks mate pattern recommended for Simscape Multibody Link:

- one concentric mate between cylindrical pivot surfaces;
- one coincident mate between planes normal to the pivot axis.

The corresponding mates are named:

- `SMLINK_BETA_CONCENTRIC`;
- `SMLINK_BETA_COINCIDENT`;
- `SMLINK_PSI_CONCENTRIC`;
- `SMLINK_PSI_COINCIDENT`.

Small cylindrical pivot features were added to the corrected parts so that the exported constraints use actual cylindrical surfaces instead of unsupported profile-centre or point/parallel combinations.

## Mass model

The pendulum component has a mass override of `0.25 kg` and its centre of mass is placed at the analytical point E. This preserves the point-mass approximation used by the differential equation. Distributed CAD masses and inertias can be introduced later as a separate model refinement.

## Validation evidence

The final XML was imported with `smimport` and produced:

- 3 Revolute Joint blocks;
- 0 Cylindrical Joint blocks;
- 0 Spherical Joint blocks;
- 0 Prismatic Joint blocks;
- no unsupported-constraint or rigid-replacement warnings.

The generated model passed a Simulink model update and a short simulation. Global signal logging is disabled in the imported model to prevent unnecessary memory use; selected joint states and sensor signals can still be logged explicitly.

The portfolio-ready generated model is:

`matlab/multibody/cad_import_final/rotating_pendulum_cad_final.slx`

## Reimporting after a CAD change

1. Open `corrected-solidworks/rotating_disk_pendulum_corrected.SLDASM`.
2. Export with **Tools > Simscape Multibody Link > Export > Simscape Multibody**.
3. Replace the XML and STEP files in `corrected-solidworks/simscape-export-corrected/`.
4. In MATLAB, run:

```matlab
cd matlab/multibody
result = import_cad_model(Overwrite=true, ...
    ModelName="rotating_pendulum_cad_final");
open_system(result.modelFile)
```

After any geometry or mate change, verify the three revolute joints again before adding controllers or comparing the CAD model with the analytical equation.

## Recommended future refinements

- Add named coordinate systems at O, A, C, D and E.
- Drive the CAD dimensions from global variables `a`, `b`, `c`, `r`, `h` and `l`.
- Add a dedicated bob part if a visually explicit mass is desired.
- Create a `Simulation_Reference` configuration for the zero-angle pose.
- Use Pack and Go before moving or sharing the native SolidWorks package.
